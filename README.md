# EclipseAndMoonAnimatorFREE
+How to Install a Plugin
Go to Plugins (top-left corner, next to View) and click Plugins Folder.
Drag the .rbxmx file into the Plugins Folder (or simply copy and paste it).
Close the folder, then close your place.
Reopen your place and check the Plugins tab.
And you're done!
 
+How to Delete a Plugin
Go to Plugins (top-left corner, next to View) and click Plugins Folder.
Delete the .rbxmx file you want to remove, then close the folder and your place.

+How to Update a Plugin
Go to Plugins (top-left corner, next to View) and click Plugins Folder.
Delete the old .rbxmx file and paste the new .rbxmx file into the folder.
Close the folder, then close your place.
Reopen your place, and you're done!
